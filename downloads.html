Before you install on Windows

Windows will warn you the first time

When you run the installer, Windows shows a blue “Windows protected your PC” screen saying the publisher is unknown.

Why it happens: Windows only recognises apps whose makers pay for a signing certificate — upwards of $200 a year. Talken is a small independent project, so for now it’s unsigned. That means “Windows doesn’t know who made this” — not that anything wrong was found in the file.

To continue: click More info, then Run anyway. Once per version, that’s it.

Want to double-check your download? (optional)

Only ever download Talken from talken.in. If you’d like to be certain the file reached you untouched, open PowerShell in your Downloads folder and run:

Get-FileHash .\TalkenSetup-3.2.exe -Algorithm SHA256

It should print exactly one of these fingerprints:

  • TalkenSetup-3.2.exe36240CCE9B0B8FCC41B7AD1509421A191E47AB234F6F4A2502C3B57FB11E6F80
  • Talken.exeB1F08D56EF7BC1B3AC063DDC2A4B21D199F3F9FA9684104EF3A0713D98503AD3
  • Talken.apkE5D92934E432D978FCD8B7A5FB4DE8AF0864F4C5AEE869AB80065D448A4BBD7A

If it doesn’t match, delete the file and download again from talken.in.

Before you install on Android

Installing on Android

Talken isn’t on the Play Store, so Android asks you to allow installs from this source the first time. That prompt is expected — it appears for any app installed outside a store.

Already running an earlier test build? Uninstall it first. Version 3.2 is signed with Talken’s permanent release key, and Android refuses to replace an app signed with a different one. Uninstalling clears that device’s message history, because messages live only on your device and only you can read them — there is no copy on a server to restore from. This is a one‑time break; updates from 3.2 onward install over the top and keep everything.

After the first install, Talken updates itself: it checks for a new version, downloads it, verifies it, and asks you before installing.

Release notes

What’s new in 3.2

Public channels: one person writes, anyone can read. Follow a channel by typing its handle — PC@handle — into the same box you use to reach a person, or create your own. Only people you allow can post to it.

Read without an account: a channel’s posts are fetched straight from storage. No sign-in, and no record anywhere of who follows what.

Channel details, properly: photo, description, follower and post counts — in the same window a contact’s profile uses. Owners can rename, set a photo, and manage who can post.

Groups got their controls back: rename, add members, promote or remove someone, leave, and delete — with members shown as a real list.

A clearer + button: it now fans out into New chat, New group and New channel. And there’s a proper Exit in the sidebar that saves everything and closes — separate from the X, which hides to the tray.

Fixed: closing the app could skip saving unless a Drive was connected; photo messages without a caption could vanish on arrival; some profiles crashed the window when opened; and on Android, Talken no longer interferes with other apps’ connections on Wi‑Fi.
